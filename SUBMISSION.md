Included: complete editable source, explicit deterministic 0–100 ecosystem model, README, educator guide, test report, attribution, automated model tests, and numbered screenshots at 360/768/1280 CSS px.

Acceptance-critical QA actually performed: identical model inputs/actions deep-compare equal; low water causes declining producers across steps; herbivores without producer food decline; restored light/water raises the model balance over repeated deterministic steps; 100-step tests keep all values finite and bounded 0–100. Browser walkthrough exercised missing-food feedback, healthy/dry/shade scenarios, prediction, manual step, auto-run/pause, reset, diagnosis, recovery and final completion. No testing with children; reduced-motion CSS is present but OS-level preference emulation was not run.
